Problem H. 困难问题

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个整数 n。请找出长度为 n 的字典序最小的排列 p，使得对于任意 1 ≤ i ≤ n，|p[i] - p[(i mod n) + 1]| 都不是质数。

输入格式

每个测试包含多个测试用例。第一行包含测试用例的数量 t（1 ≤ t ≤ 10^4）。接下来是测试用例的描述。

每个测试用例的唯一一行包含一个整数 n（2 ≤ n ≤ 2×10^5）。

保证所有测试用例中 n 的总和不超过 2×10^5。

输出格式

对于每个测试用例，如果不存在符合条件的长度为 n 的排列，请输出 -1。

否则，输出 n 个互不相同的整数 p1, p2, …, pn（1 ≤ pi ≤ n），表示你找到的排列 p。

样例

标准输入 标准输出
2 1 2
2 -1
3

题解

这是一个构造类问题，需要构造出一个字典序最小的排列使得每两个相邻的数字之差都不是质数，其中p[1]与p[n]相邻。很容易就能想到字典序最小则一定是以1开头，而且1也不是质数，因此我们可以直接按照从1到n进行排列，会发现只要满足n-1不是质数即可，其中偶数除了2以外都不是质数，也就是说n为奇数且不为3的时候一定可以构造出一个合法的排列。而如果n为偶数的话需要检查n-1是否是质数，可以使用埃氏筛来筛选质数并查找。如果n-1是质数的话，我们从后往前考虑，因为最好构建的非质数就是1，而结尾不能是n，那么我们将n到n-k颠倒过来，从第n-k位开始按照n，n-1，n-2…n-k的顺序构造，这样只要满足k+1不是质数且n-k-1不是质数即可，枚举发现k为3的时候满足条件，此时n大于等于8，因此我们将部分点特殊处理后进行普遍处理即可。（此规律也可通过打表找规律发现）

Problem G. 图上游戏

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个简单连通无向图 G，包含 n 个顶点和 m 条边，以及一个由 k 个特殊顶点 a1, a2, …, ak 组成的集合。G 有一个有趣的性质：所有顶点的度数不超过三。

考虑在 G 上进行的以下游戏：

  • 游戏由两名玩家 Alice 和 Bob 参与。初始时，Alice 站在一个非特殊顶点 s 上。然后，两名玩家轮流操作，由 Alice 先手：

    • 如果轮到 Alice 操作，假设她当前在顶点 u。如果 u 是特殊顶点，游戏结束且 Alice 获胜。否则，她选择一个与 u 有边相连的顶点 v 并移动到 v。如果不存在这样的顶点，游戏结束且 Bob 获胜。
    • 如果轮到 Bob 操作，他会选择 G 中剩余的任意一条边并将其删除。如果 G 中没有边了，他什么也不做。

  • 可以证明游戏会在有限回合内结束。在整个游戏过程中，Alice 的位置对两名玩家都是已知的。

一个顶点 u 被认为是必胜的，当且仅当：

  • u 不是特殊顶点；
  • 如果初始时 Alice 站在顶点 u 上，在双方都采取最优策略的情况下，她能赢得游戏。

找出所有必胜顶点。

输入格式

每个测试包含多个测试用例。第一行包含测试用例的数量 t（1 ≤ t ≤ 2×10^4）。接下来是测试用例的描述。

每个测试用例的第一行包含三个整数 n、m 和 k（1 ≤ k < n ≤ 2×10^5，n-1 ≤ m ≤ min(3n/2, 2×10^5)），分别表示 G 中的顶点数、G 中的边数和特殊顶点的数量。

接下来的 m 行，每行包含两个整数 u 和 v（1 ≤ u, v ≤ n, u ≠ v），表示连接顶点 u 和 v 的一条边。保证 G 不包含自环或重边。此外，保证所有顶点的度数不超过三。

下一行包含 k 个互不相同的整数 a1, a2, …, ak（1 ≤ ai ≤ n），表示特殊顶点。

保证所有测试用例中 n 的总和与 m 的总和均不超过 2×10^5。

输出格式

对于每个测试用例，首先输出一个整数 c（1 ≤ c ≤ n-k），表示必胜顶点的数量。然后，输出 c 个互不相同的整数 w1, w2, …, wc（1 ≤ wi ≤ n），表示必胜顶点。你可以以任意顺序输出这些顶点。

样例

标准输入 标准输出
4 1
2 1 1 2
1 2 1
1 2
3 2 1 2
1 2 1 2
2 3 2
1 2 3
4 3 2
1 2
2 3
2 4
3 4
4 5 1
1 2
1 3
2 4
3 4
2 3
4

题解

本题是一个博弈论问题，根据规则，很容易就能想到与特殊点相邻的点是必胜点，再往深了思考，轮到Bob的回合的时候，Alice要想赢，她就必须要有两条路可以获胜，这样不管Bob删除哪一条路，Alice都有另一个选择可以获胜。我们构造一种点称为安全点，只要处于这个点，此时不管轮到谁Alice都是必胜的。不难发现，特殊点都是安全点，并且基于刚才的分析，一个点是安全点，当且仅当这个点有两个邻居是安全点。因此我们可以从特殊点开始往外遍历，记录每一个点的安全点的邻居数，并不断更新，最终安全点里除去特殊点之外的点就是必胜点。

Problem F. 字母表

输入文件： 标准输入
输出文件： 标准输出
时间限制： 10 秒
内存限制： 1024 MB

在本题中，字母表被定义为小写英文字母从 a 到 z 的一个排列。在字母表 A 下，字母 x 的字典序小于字母 y 当且仅当在 A 中 x 出现在 y 之前。

在字母表 A 下，字符串 s 的字典序小于字符串 t 当且仅当满足以下两个条件之一：

  • s 是 t 的真前缀。
  • 存在一个整数 i（1 ≤ i ≤ min(|s|, |t|)），使得对于所有的 1 ≤ j < i 都有 s[j] = t[j]，并且在字母表 A 下 s[i] 的字典序小于 t[i]。

在字母表 A 下，字符串 s 被称为一个 Lyndon 串，当且仅当在 A 下它的字典序严格小于其所有的非空真后缀。

给定一个字符串 s。请计算有多少种不同的字母表 A 使得 s 在 A 下是一个 Lyndon 串。由于答案可能很大，请输出其对 2^32 取模后的余数。

输入格式

每个测试点仅包含一行，给出一个字符串 s（2 ≤ |s| ≤ 2×10^7）。

输出格式

输出一个整数，表示使得 s 在字母表 A 下是 Lyndon 串的不同字母表 A 的数量对 2^32 取模的结果。

样例

标准输入 标准输出
abcdefghijklmnopqrstuvwxyz 2076180480
abaabb 0
sserxhsfan 2452619264
arcabcagc 3598712832
