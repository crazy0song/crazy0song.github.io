Problem I. Rounddog II

**题目原地址：**https://ac.nowcoder.com/acm/contest/133879/I

输入文件： 标准输入
输出文件： 标准输出

你是 Rounddog 的狂热粉丝，所以你要出一道关于 Rounddog 的题目。

设 T1 = Rounddog。
对于每个整数 i > 1，定义 Ti = Ti-1 + g，其中 + 表示字符串拼接。
换句话说，Ti 是字符串 Rounddo 后面紧跟着恰好 i 个字符 g。

给定一个字符串 S 和一个整数 k。考虑 S 的所有循环移位。
字符串 S 的一个循环移位是通过选择一个位置，并将该位置之前的前缀移动到字符串末尾得到的。例如，abcd 的循环移位有 abcd、bcda、cdab 和 dabc。

你的任务是统计有多少个 S 的循环移位包含 Tk 作为一个连续子串。

输入格式

第一行包含一个整数 t（1 ≤ t ≤ 10^5），表示测试用例的数量。

对于每个测试用例：

  • 第一行包含一个字符串 S（1 ≤ |S| ≤ 10^5）；
  • 第二行包含一个整数 k（1 ≤ k ≤ 100）。

保证所有测试用例中 |S| 的总和不超过 10^5，并且 S 只包含大写字母和小写字母。

输出格式

对于每个测试用例，输出一个整数，表示包含 Tk 作为连续子串的循环移位数量。

样例

标准输入 标准输出
3 12
Rounddoggggggggggggggggg 8
6 0
RounddogRounddo
1
abcdefgabcdegf
2

题解

这个题我们需要匹配给定的字符串和输入的字符串。观察可以发现给定的字符串一定是以大写的R开头的，那么我们就可以在输入的字符串中只搜索R出现的位置，然后搜索到了就与Tk进行匹配，如果每一位都相同那么cnt++。同时要注意输入的字符串是可以进行循环移位的，那么我们就可以将s直接拼接在自己后面，这样相当于进行了循环移位，接下来的循环中就只用移动滑动窗口就行了。

接下来就是根据cnt的值求答案，如果cnt是0，答案显然是0，如果cnt是1，答案就是s的长度减去tk的长度再加一，可以理解为在保证tk连续的出现在s中的情况下任意循环移位。如果cnt大于1，那么任何循环移位都会至少有一个连续的tk出现在s中，因为循环移位最多破坏一个tk，另一个tk必定是完整的。

Problem C. 重测队列

**题目原地址：**https://ac.nowcoder.com/acm/contest/133879/C

输入文件： 标准输入
输出文件： 标准输出

一次大型比赛结束后，评测集群还要做一次复查：把 n 个程序在同一套 m 个测试点上重新评测。每个程序都会使用同一个测试点队列。

评测机处理一个程序时，会从队列开头依次运行测试点。一旦某个测试点给出拒绝结果，评测机在运行完这个测试点后立刻停止处理这个程序。通过全部测试点的程序会运行完整个队列。

复查开始前，历史日志已经给出了每个程序在每个测试点上的表现。第 i 个程序运行第 j 个测试点需要 d[i][j] 的时间，结果要么是接受，要么是拒绝。无论结果如何，只要这个测试点被实际运行，d[i][j] 都会计入集群总耗时。

你可以在复查前任意重排这 m 个测试点。求评测完全部 n 个程序所需的最小总耗时。

输入格式

第一行包含两个整数 n 和 m，分别表示程序个数和测试点个数。

接下来 n 行，第 i 行描述第 i 个程序。每行先包含 m 个整数 $d_{i,1}$, $d_{i,2}$, …,$d_{i,m}$，随后包含一个长度为 m 的字符串 s[i]。若 s[i] 的第 j 个字符为 A，表示第 i 个程序在第 j 个测试点上的结果是接受；若为 R，表示结果是拒绝。

保证：

  • 1 ≤ n ≤ 2×$10^4$
  • 1 ≤ m ≤ 20
  • 1 ≤ $d_{i, j}$ ≤ $10^9$
  • s[i] 仅包含字符 A 和 R

输出格式

输出一个整数，表示最小可能的总耗时。

样例

标准输入 标准输出
3 3 27
3 10 2 ARA
5 1 4 RAA
2 2 7 AAR

题解

这个题涉及到的算法有sos dp和状压dp。首先我们考虑将数据按照在第几位是R按二进制存起来，是R为1，不是为0。然后我们考虑怎样让一个状态的耗时总和最小，可以很自然的想到去考虑它的子集，在他的子集中找到加上下一个测试点后耗时最小的那一个，并将其赋值给这个状态。我们记dp[i]为**选取的测试点为i时所耗的最小时间。**例如，dp[3]中i的掩码为11，也就是已选取的测试点为1和2。

接下来我们要考虑R的情况，当一个程序的测试点的结果为R时，之后的测试点都不会运行，因此我们需要使用SOS dp，把所有之前存下来的时间数据根据R的掩码排列求前缀和，比如g[3] [j]就包括了g[1] [j]和g[2] [j]。基于此种变换，我们就可以很方便的算出cost。比如我们要求dp[7]，其掩码为111，子集是101，110，011，我们就可以遍历找到下标为这几个子集的数据，并将其加上cost。cost的计算方法为:假设此时掩码为mask，我们设一个步长step=1，每次将step左移一位，将左移的位数记作j，并和mask按位与运算，保证mask第j + 1位为1，然后我们对mask和1<<j进行异或运算，可以得到消除了第j+1位的mask，即mask的一个最大真子集，记这个真子集为prev，我们再对prev求补集，得到一个未选集合complement。程序i还没有停可以翻译为这个程序的掩码Ri和已选集合的交集是空集，即Ri是complement的子集。而g[complement] [j]又包含了complement的所有子集，即所有的还在运行的程序。因此cost = g[complement] [j], dp[mask] = min(dp[mask], dp[prev] + cost)。

Problem D. The Game

输入文件： 标准输入
输出文件： 标准输出

Alice 和 Bob 正在玩一个游戏。

初始时，有一个空序列。他们会得到一个整数 n，并共同构造一个长度为 n 的排列 p。

Alice 先手。每一步中，当前玩家需要从 1 到 n 中选择一个此前尚未被选择过的整数，并将其添加到序列末尾。恰好进行 n 步后，该序列将成为 1, 2, …, n 的一个排列 p。

对于排列 p = (p1, p2, …, pn)，它的一个循环移位是指：选择一个下标 i（1 ≤ i ≤ n），并得到序列 (pi, pi+1, …, pn, p1, p2, …, pi-1)。

例如，排列 (2, 3, 1) 的所有循环移位为 (2, 3, 1)、(3, 1, 2) 和 (1, 2, 3)。

对于一个排列 p，定义 f(p) 为 p 的所有循环移位中字典序最小的一个。

Alice 希望让 f(p) 的字典序尽可能小，而 Bob 希望让它的字典序尽可能大。

假设双方都采取最优策略，请求出最终得到的排列 f(p)。

输入格式

第一行包含一个整数 T（1 ≤ T ≤ 10^5），表示测试用例的数量。

接下来 T 行，每行包含一个整数 n（1 ≤ n ≤ 5×10^5）。

保证所有测试用例中 n 的总和不超过 5×10^5。

输出格式

对于每个测试用例，输出 n 个整数，表示双方均采取最优策略时最终得到的排列 f(p)。

样例

标准输入 标准输出
4 1
1 1 2
2 1 3 2
3 1 3 2 4
4

题解

根据题意可知，我们可以将排列进行任意的循环移位，因此f(p)必定以1开头，所以在博弈中1的位置很关键。我们可以考虑Alice和Bob分别控制的位置，发现Alice控制的是第奇数个位置，而Bob控制的是第偶数个位置，由于1后面的那一位至关重要，所以Alice和Bob都不会先选1，都希望对方选1，这样自己就能控制1后的一位，因此我们可以认为1是最后被迫放置的，在此之前，Alice希望字典序尽可能小，所以Alice会尽量消耗大数，同理Bob会尽量消耗小数，又因为1一定是最后放的，所以Alice在希望字典序尽可能小的情况下会把大数中小的部分往前放，同理Bob会把小数中大的部分往前放。此规律在n为偶数时适用，因为n为偶数时最后一位必定留给Bob放，对Alice没什么影响。而在n为奇数的情况下，Alice需要放置1，那么就会希望第一位尽量小，因此会在第一位放置2，而Bob为了防止Alice这样做就会提前放1，因此Bob就会在第倒数第二位放1，最后一位由Alice放。
