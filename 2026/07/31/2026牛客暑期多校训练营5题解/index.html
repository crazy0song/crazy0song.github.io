Problem I. 题列序 2

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个整数 n，令 N = 2^n - 1。你有一个长度为 N 的 01 串 s，下标从 1 到 N。

现在依次进行 N 个操作，操作编号为 x = 1, 2, …, N。对于第 x 个操作，你可以选择以下两种行动之一：

  • 跳过：不进行任何操作；
  • 执行翻转：选择一对整数 (y, z)，满足 1 ≤ y, z ≤ N，y ≠ z，且 x = y ⊕ z，其中 ⊕ 表示按位异或运算。然后同时翻转位置 x、y、z 上的二进制位（即 0 变 1，1 变 0）。

你需要给出一种操作方案，使得最终整个二进制串中至多只有一个位置上的值为 1。输出时，若执行第 x 个操作，只需给出 y，而 z 由 z = x ⊕ y 唯一确定。可以证明一定有解。

输入格式

第一行包含一个整数 T（1 ≤ T ≤ 1000），表示测试数据组数。

每组测试数据包含两行：

  • 第一行包含一个整数 n（1 ≤ n ≤ 20）；
  • 第二行包含一个长度为 N = 2^n - 1 的 01 串 s，表示初始二进制串。

保证所有测试数据的 ∑N ≤ 2×10^6。

输出格式

对于每组测试数据，输出一行 N 个整数 b1, b2, …, bN，其中 bx 描述第 x 个操作：

  • 若不进行操作，令 bx = 0；
  • 否则，令 y = bx、z = x ⊕ y，并执行对位置 x, y, z 的翻转。此时必须满足 1 ≤ y, z ≤ N。

样例

010 0 3 0

题解

本题我们需要按照要求进行操作，需要输出N个数字表示操作，不为0的话就要将第K个数字与K取异或然后将这三个数对应的序号全部翻转。注意到每一次操作都会对后面的操作有影响，因此操作需要按顺序存下来。注意到双指针的快指针是单调递增的，因此我们可以用双指针的快指针作为答案的索引，慢指针作为值存下来，即ans[i] = l。注意字符串下标也是从左往右的，而不是从低位到高位（比赛的时候犯蠢了）。还可以进行一个优化处理，在输入字符串的前面加上一个” “用来占位，这样下标更清晰。

Problem L. 又一个矩阵问题

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 1024 MB

给定一个大小为 n × m 的整数矩阵 a。

你可以进行任意多次如下操作：选择一条从 (1, 1) 出发到达 (n, m) 的路径，每次移动只能向右或向下，然后将该路径经过的所有格子上的数值增加 1。

你的目标是使矩阵中所有元素的值均相等。

请求出最少需要的操作次数；如果无法达成目标，请输出 -1。

输入格式

第一行包含一个整数 T（1 ≤ T ≤ 5000），表示测试数据组数。

每组测试数据的第一行包含两个整数 n, m，表示矩阵的行数和列数。接下来 n 行，每行包含 m 个整数，表示矩阵 a，其中第 i 行第 j 列的元素为 $a[i][j](-10^9 ≤ a[i][j] ≤ 10^9)$。

保证所有测试数据满足 1 ≤ ∑n, ∑m ≤ 5000。

输出格式

对于每组测试数据，输出一行一个整数，表示该组数据的最少操作次数。若无法使矩阵中所有数相等，则输出 -1。

样例

标准输入 标准输出
2 1
2 3 2
1 1 1
2 2 1
3 2
1 2
2 2
2 1

题解

我们可以列出以下式子:$a + k = \frac{b + c + k}{2}$。根据计算我们可以知道操作次数k=b + c - 2a，最后矩阵的里的数会变成X=a + k，然后我们可以通过x和原矩阵相减得到一个新矩阵，描述的是在b[i] [j]处有多少条路径会经过此处。然后我们检查这样的矩阵是否能够由k条路径拼接而成即可。注意要进行特判，即只有一行或者一列或者一格的情况。

check的逻辑是，从上到下依次拆分每一行的流量，看每一行是否能与构造出来的矩阵b对应，若能对应则有解，否则无解。

Problem C - 数字游戏

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个正整数进制 B。

你需要构造三个长度为 B 的排列 P, Q, R（即每个序列恰好包含 0 到 B-1 每个数字一次）。

P = (p1, p2, …, pB), Q = (q1, q2, …, qB), R = (r1, r2, …, rB)

定义一个序列 X = (x1, x2, …, xB) 在 B 进制下表示的整数为：

[X]B = Σ_{i=1}^{B} x_i · B^{B-i}

注意：序列允许以数字 0 开头，因此表示的整数可以小于 B^{B-1}。

请你构造三个排列 P, Q, R，使得它们满足等式（注意加法是在 B 进制下的加法）：

[P]B + [Q]B = [R]B

并且对于每个位置 i（1 ≤ i ≤ B），pi, qi, ri 两两不同。

如果不存在这样的构造，请输出 -1。

输入格式

输入仅一行，包含一个整数 B（2 ≤ B ≤ 10^6）。

输出格式

如果存在合法构造，则输出三行，每行 B 个整数，分别表示序列 P, Q, R 中的数字，数字之间用空格分隔。

如果不存在合法构造，则输出一行 -1。

若存在多种构造，输出任意一种即可。

样例

标准输入 标准输出
5 -1
6 4 2 5 0 3 1
0 4 1 2 5 3
5 1 0 3 2 4

题解

本题是一个构造题，我们可以先从题目条件下手，考虑每一位B进制下的加法，有 $p_i+q_i+c_i−1=r_i+B⋅c_i$,再进行累加处理，得到$\sum p_i+\sum q_i+ \sum c_{i−1}=\sum r_i+B⋅\sum c_i$。又$c_n=c_0=0$，则$\sum c_i = \sum c_{i - 1}$，又$\sum p_i=\sum q_i = \sum r_i=\frac{B(B-1)}{2}$，代入上式得$\sum c_i=\frac{B}{2}$。则当B为奇数时无解，同时B=2时也无解。

  • P：交替放置”小数”（0∼k−10∼k−1）和”大数”（k∼2k−1k∼2k−1）：

    P=[0,  k,  1,  k+1,  2,  k+2,  …,  k−1,  2k−1]

  • Q：Qi=(Pi+2)modB

  • R：模拟 B 进制加法 P+Q 得到
