Problem K. 转向导航

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

车载导航系统引导驾驶员沿着地图上绘制好的规划路线行驶。我们采用平面的标准方向：$x$ 轴正方向指向东，$y$ 轴正方向指向北。

路线由 $n$ 个航点 $P_1, P_2, \ldots, P_n$ 组成，每个航点具有整数坐标。汽车沿直线段行驶，始终向前移动：先从 $P_1$ 行驶到 $P_2$，再从 $P_2$ 行驶到 $P_3$，依此类推，直到到达 $P_n$。

每当汽车经过一个中间航点 $P_i$（$2 \le i \le n-1$）时，系统会播报驾驶员在该处的转弯情况。系统将汽车到达的方向（从 $P_{i-1}$ 到 $P_i$）与离开的方向（从 $P_i$ 到 $P_{i+1}$）进行比较：

  • 如果离开方向是由到达方向逆时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向左转，系统播报 LEFT；
  • 如果是由到达方向顺时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向右转，系统播报 RIGHT；
  • 如果方向完全不变，则汽车继续直行，系统播报 STRAIGHT。

保证汽车绝不会掉头，因此离开方向绝不会与到达方向恰好相反。于是，每个中间航点处恰好适用三种播报中的一种。

给定路线，按顺序输出每个中间航点的播报。

输入格式

每个测试文件包含多组测试数据。第一行包含测试数据的组数 $T$（$1 \le T \le 500$）。每组测试数据的格式如下：

每组测试数据的第一行包含一个整数 $n$（$3 \le n \le 10^5$），表示路线上的航点数。

接下来 $n$ 行，每行包含两个整数 $x_i$ 和 $y_i$（$-10^9 \le x_i, y_i \le 10^9$），表示第 $i$ 个航点 $P_i$ 的坐标，按汽车经过的顺序给出。保证每两个相邻航点互不相同（对所有 $1 \le i \le n-1$ 都有 $P_i \ne P_{i+1}$），且汽车绝不会掉头（对所有 $2 \le i \le n-1$，从 $P_i$ 到 $P_{i+1}$ 的方向与从 $P_{i-1}$ 到 $P_i$ 的方向不会恰好相反）。

保证同一测试文件中所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

输出格式

对于每组测试数据，输出中间航点 $P_2, P_3, \ldots, P_{n-1}$ 的播报。每个播报是字符串 LEFT、RIGHT 或 STRAIGHT 之一。

样例

standard input standard output
2 LEFT LEFT
4 STRAIGHT RIGHT
0 0
1 0
1 1
0 1
4
0 0
2 0
4 0
4 -2

本题不涉及算法，从数学角度分析即可。题目要求出中转点处的方向是左转还是右转，假设中转点是第k个点，那么k处的播报涉及到第k-1个点和第k+1个点，我们可以利用第k个和第k-1个点，第k个和第k+1个点的坐标求出两个向量，两个向量的夹角的正弦值就可以反映出播报的方向，因此我们将这两个向量做叉乘，如果是正的就是向左转，如果是负的就是向右转，如果是0就是直行。

Problem L. 登山对决

原题链接： https://ac.nowcoder.com/acm/contest/133878/L

输入文件： 标准输入
输出文件： 标准输出

两名登山者，先手玩家和后手玩家，在一张山地地图上博弈。

地图是一个 n 行 m 列的网格。第 i 行第 j 列的格子有一个整数高度 h[i][j]。地图上所有高度互不相同：没有两个格子具有相同的高度。

一个格子上放有一面旗帜。两名玩家交替移动旗帜，先手玩家先手。一名玩家的回合中：

  • 该玩家必须将旗帜从当前格子移动到一个四相邻（共享一条边）且高度严格更高的格子；
  • 如果当前格子不存在四相邻且高度严格更高的格子，则轮到移动的玩家无法移动并输掉游戏，另一方获胜。

由于每次移动都到一个严格更高的格子，旗帜永远不会回到它已经离开的格子，因此游戏总会在有限步之内结束。双方都采取最优策略。

给定 q 个独立的询问。每个询问指定旗帜的起始格子；地图本身在询问之间不会改变。对于每个询问，判断在双方最优博弈下谁会获胜：先手玩家还是后手玩家。

输入格式

每个测试文件包含多组测试数据。第一行包含测试数据的组数 T（1 ≤ T ≤ 500）。每组测试数据的格式如下。

每组测试数据的第一行包含两个整数 n 和 m（1 ≤ n, m ≤ 10^5，n·m ≤ 10^5），分别表示地图的行数和列数。

接下来 n 行描述高度。其中第 i 行包含 m 个整数 h[i][1], h[i][2], …, h[i][m]（1 ≤ h[i][j] ≤ 10^9），其中 h[i][j] 为第 i 行第 j 列格子的高度。保证同一组测试数据内的 n·m 个高度互不相同。

接下来一行包含一个整数 q（1 ≤ q ≤ 10^5），表示询问数。

接下来 q 行，每行包含两个整数 r 和 c（1 ≤ r ≤ n，1 ≤ c ≤ m），表示该询问中旗帜的起始格子为第 r 行第 c 列。

保证同一测试文件中所有测试数据的 n·m 之和不超过 10^5，q 之和不超过 10^5。

输出格式

对于每个询问，输出一行：如果先手玩家在最优博弈下获胜则输出 First，如果后手玩家获胜则输出 Second。

样例

标准输入 标准输出
1 First
2 3 Second
1 2 3 Second
6 5 4 Second
5 First
1 1
1 2
2 1
2 3
2 2

题解

这道题目本质上是一个在有向无环图的上的博弈，由于只能从低处往高处走，所以节点标号小的节点会指向节点标号大的节点，直到一个节点的出度为0。我们可以从高到低去考虑节点的状态（因为高的节点周围只会要么存在胜负确定的格子，要么存在更低的格子），用win[i] [j]来存储先手是否获胜。一个节点要想先手必胜，那么与之相邻的格子必须至少有一个是先手必败，而且从这个格子可以走到那个相邻的格子，即这个格子的高度要小于必败格子的高度。（可以这样想，若存在这样的格子，先手方第一步走到这样的格子，那么后手方就成了在这个必败格子上先手方，即后手必败，先手必胜）。按这样的思路把win填满，查询的时候直接查表就能得到结果。

Problem B. 再买一瓶

输入文件： 标准输入
输出文件： 标准输出

一瓶饮料售价 1 元。

每次小明喝完一瓶饮料，他会以 a/b 的概率获奖。如果获奖，他将得到 c 元；否则，他什么也得不到。他得到的钱可以用来购买更多饮料。每瓶饮料的获奖事件相互独立。

小明一开始有 n 元。求他恰好喝完 m 瓶饮料后花光所有钱的概率。

输入格式

每个测试文件包含多组测试数据。第一行包含测试数据的组数 T（1 ≤ T ≤ 200000）。每组测试数据的格式如下。

接下来 T 行，每行包含五个整数 n、m、c、a、b（1 ≤ n, m, c ≤ 2000000，0 ≤ a < b < 998244353），表示小明一开始有 n 元，每次获奖得到 c 元，获奖概率为 a/b；你需要求出他恰好喝完 m 瓶饮料的概率。

输出格式

输出 T 行，每行包含一个整数：对应测试数据的答案对 998244353 取模的结果。

形式化地，设 M = 998244353。可以证明，答案可以表示为最简分数 p/q，其中 p 和 q 为整数且 q ≠ 0 (mod M)。输出等于 p · q^(-1) mod M 的整数。

样例

标准输入 标准输出
4 499122177
1 1 2 1 2 873463809
1 3 2 1 2 776412275
2 2 3 1 3 0
1 2 2 1 2

题解

这个题涉及到组合数学的算法，是一个带吸收壁的随机游走模型。基于Kemperman 公式，我们可以得到一个随机游走的模型在初始为n并且走到第m步时第一次归零时的概率为$P_m =\frac{n}{m}P_{m自由}$，那么接下来我们只需要只需要求出在随机游走的情况下能到达归零时的状态的概率就行了。已知m步中有k次中奖，刚好花完这么多钱则有 $S_m=n+kc−m=0$，由于k一定是一个整数，所以$\frac{m - n}{c}$必须是整数，否则概率为0。接下来要求的就是中k次奖的概率，即:$P = \frac{n}{m} \cdot \binom{m}{k} \cdot p^k \cdot q^{m-k}$

但是由于这个题要对998244353取余，而且原公式中有除法存在，所以要取m的逆元。由于要多次询问，我们可以打一个表存储阶乘和阶乘的逆元，涉及到幂数计算的部分用快速幂即可，接下来一步步算就行了，记得取模。

Problem F. Not Aqre 2

输入文件： 标准输入
输出文件： 标准输出

给定一个 n × m 的网格。你需要在每个格子中填入 0、1、2 中的一个整数。

如果任意两个共享一条边的格子填有不同的整数，则称该填法为好的。

输出好的填法数对 998244353 取模的结果。

输入格式

每个测试文件仅包含一组测试数据。

唯一一行包含两个整数 n 和 m（1 ≤ n < 10，1 ≤ m < 998244353）。

输出格式

输出一个整数表示答案。

样例

标准输入 标准输出
2 2 18

题解

这个题是一个染色问题。注意到n很小而m很大，所以可以按列处理，定义一个 一个长度为 n 的数组 col[0..n-1]，每个元素 ∈ {0,1,2}，且 col[i] ≠ col[i+1]。接下来，我们可以将所有满足这个条件的状态存起来，并创建一个矩阵来存储状态之间的关系，即这个状态后面一列能不能填另一个状态，能即为1，不能即为0。但是会发现当n为9的时候，状态多达768，转移矩阵T的大小为768*768，哪怕用矩阵快速幂（ O(K³ log m) ）也会超时，因此要压缩状态。

不难发现其实0，1，2本质上是一种颜色，他们是等价的，你可以让0是1，让1是0，因此我们可以把之前的状态压缩下来，定义状态中从前往后第一次出现的颜色分别为0，1，2，这样就可以将多种状态压缩下来。例如，010和212本质上属于同一个等价类。

接下来我们需要记录每一个等价类里面有多少种情况，用一个cnt数组存第i个等价类有多少个具体状态，再用一个转移矩阵trans[p] [q]表示从模式p到q有多少种转移方式。 cnt[p] = P(3, k) ，即从三种颜色里面选出k种并进行排列的方法数。然后填充trans,从0，1，2中选取k个填充p的具体模式，然后逐项比较，所有的A[i]≠B[i]的情况下trans[p] [q]加一。这步可以暴力解决，因为只有三个颜色。再构建一个初始向量v，v[p] = cnt[p]，v里面存的是所有模板对应的方案数，之后第m列的方案数我们只需要通过矩阵乘法v×trans的m-1次方就可以得到，v×trans^(m-1) 得到的是第 m 列各模板的方案分布，把所有分量加起来就是总方案数（因为每条路径已包含中间所有列的选择）。

Problem G. 矩阵标记

输入文件： 标准输入
输出文件： 标准输出

给定一个 n × m 的数字网格，每个格子中包含一个正整数。

如果存在两个格子 (r1, c1) 和 (r2, c2) 满足 r1 < r2 且 c1 < c2，且这两个格子中的数字相等，那么所有满足 r1 ≤ r ≤ r2 且 c1 ≤ c ≤ c2 的格子 (r, c) 都会被标记。

输出整个网格最终的标记情况。

输入格式

每个测试文件仅包含一组测试数据。

第一行包含两个整数 n、m（1 ≤ n, m，n × m ≤ 1000000）。

接下来 n 行，每行包含 m 个整数；其中第 i 行包含 a[i][1], a[i][2], …, a[i][m]（1 ≤ a[i][j] ≤ n × m），描述该数字网格。

输出格式

输出 n 行，每行包含一个长度为 m、由字符 0 和 1 组成的字符串。

第 i 行的第 j 个字符为 1 表示格子 (i, j) 最终被标记，为 0 表示未被标记。

样例

标准输入 标准输出
2 6 001110
1 2 3 4 5 6 001110
7 8 9 3 4 10

题解

对每种数字独立处理。将数字 $v$ 的所有出现位置按行升序、同行按列升序排列（本题中用链表收集后反转即可得到该顺序）。由于只有跨行的配对（$r_1<r_2$）才会产生矩形，我们可将每行的点压缩为该行的最小列 $l_i$ 和最大列 $r_i$。

记该数字出现的行（去重排序）为 $\text{rows}1<\dots<\text{rows}k$，对应每行的 $l_i$ 和 $r_i$。定义前缀最小列 $p_l[i]=\min{1\le t\le i} l_t$ 和后缀最大列 $s_r[i]=\max{i\le t\le k} r_t$。

  • 对于 $\text{rows}i$ 和 $\text{rows}{i+1}$ 之间的空行（行号在 $\text{rows}i+1$ 到 $\text{rows}{i+1}-1$），若 $p_l[i] < s_r[i+1]$，则这些行被覆盖的列区间为 $[,p_l[i],, s_r[i+1],]$。
  • 对于有效行 $\text{rows}_i$ 本身：
    • 若它作为上方点（$i<k-1$ 且 $p_l[i]<s_r[i+1]$），产生区间 $[,p_l[i],, s_r[i+1],]$；
    • 若作为下方点（$i>0$ 且 $p_l[i-1]<s_r[i]$），产生区间 $[,p_l[i-1],, s_r[i],]$。
      该行的最终标记列区间是上述两区间的并集（有重叠则合并，否则分别为两个区间）。

对每种数字产生的所有矩形，使用二维差分进行区间加。全部处理完后求一次二维前缀和，标记次数 $>0$ 的格子输出 1，否则输出 0。总复杂度 $O(nm)$。

Problem J. 树.zip

输入文件： 标准输入
输出文件： 标准输出

给定一棵以顶点 1 为根的树，树有 n 个顶点，编号从 1 到 n。

你需要构建一棵新树，同样以顶点 1 为根，使用相同的 n 个顶点，并满足以下条件：对于每个顶点 x ≠ 1，它在新树中的父顶点必须是 x 在原树中的祖先。

此外，给定 q 个约束。每个约束的形式为 (u, v)，表示在新树中 u 必须是 v 的后代，等价地，v 必须是 u 的祖先。

设 dep[i] 为顶点 i 在新树中的深度，其中根 1 的深度为 0。最小化 ∑dep[i]，并输出该最小值。

输入格式

每个测试文件仅包含一组测试数据。

第一行包含两个整数 n、q（2 ≤ n ≤ 500000，0 ≤ q ≤ 500000）。

接下来 n-1 行，每行包含一个整数；其中第 (i-1) 行包含一个整数 p[i]（1 ≤ p[i] < i），表示在原树中顶点 i 的父顶点是 p[i]。

接下来 q 行，每行包含两个整数 u、v（2 ≤ u ≤ n，1 ≤ v ≤ n），描述一个约束：在新树中 u 必须是 v 的后代。保证 u ≠ v，且 v 是 u 在原树中的祖先。

输出格式

输出一个整数：∑dep[i] 的最小可能值。

样例

标准输入 标准输出
7 4 11
1
2
3
3
2
6
4 2
4 3
5 2
7 2

题解

本题本质上是要在满足若干“祖先后代”约束的前提下，给每个节点（除根外）选择一个尽可能浅的祖先作为新父节点，以最小化深度之和。因为越浅的父节点意味着越小的深度，但必须满足所有给定约束，即 u 的父节点深度不能低于 depth[v]（v 是给定祖先）。

我们采用贪心策略从叶子向根处理：对于每个节点 u，维护一个集合，记录所有以 u 为下端点的约束——即所有要求 u 是某个祖先 v 的后代的约束。当为 u 选择父节点时，必须选一个深度至少为这些约束中最大深度的祖先。为了让 u 的深度尽量小，最优选择恰是这些约束中深度最大的那个 v 作为父节点；如果没有任何约束，直接选根 1 作为父节点。当 u 的父节点选定后，剩余未满足的约束（即来自 u 但深度小于选定父节点深度的那些）需要向上传递给选定的父节点继续处理，因为它们现在变成了对父节点的约束。

这一过程可以使用可并堆（左偏树）高效实现。具体做法：

  1. 读入原树，预处理每个节点的深度originaldepth。
  2. 对于每个约束 (u, v)，在节点 u 的可并堆中插入一个值为 v 的节点（按深度作为键值构建最大堆）。
  3. 从 n 到 2 逆序遍历节点 u（相当于自底向上），处理节点 u 的堆：
    • 取出堆顶元素 v（即深度最大的约束祖先）。如果堆顶有多个相同的 v，全部弹出（重复约束只计一次）。
    • 将 u 的新父节点设为 v。若堆为空，则父节点设为 1。
    • 将 u 的堆中剩余元素（已弹出重复 v 后剩下的）合并到父节点 v 的堆中，因为这些约束现在传递给了 v。
  4. 所有父节点确定后，从根向下计算新深度并累加即可得到答案。

由于每个约束只会被插入和弹出各一次，总复杂度为 O((n + q) log q)，可以轻松通过。
