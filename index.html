Problem I. Rounddog II

**题目原地址：**https://ac.nowcoder.com/acm/contest/133879/I

输入文件： 标准输入
输出文件： 标准输出

你是 Rounddog 的狂热粉丝，所以你要出一道关于 Rounddog 的题目。

设 T1 = Rounddog。
对于每个整数 i > 1，定义 Ti = Ti-1 + g，其中 + 表示字符串拼接。
换句话说，Ti 是字符串 Rounddo 后面紧跟着恰好 i 个字符 g。

给定一个字符串 S 和一个整数 k。考虑 S 的所有循环移位。
字符串 S 的一个循环移位是通过选择一个位置，并将该位置之前的前缀移动到字符串末尾得到的。例如，abcd 的循环移位有 abcd、bcda、cdab 和 dabc。

你的任务是统计有多少个 S 的循环移位包含 Tk 作为一个连续子串。

输入格式

第一行包含一个整数 t（1 ≤ t ≤ 10^5），表示测试用例的数量。

对于每个测试用例：

  • 第一行包含一个字符串 S（1 ≤ |S| ≤ 10^5）；
  • 第二行包含一个整数 k（1 ≤ k ≤ 100）。

保证所有测试用例中 |S| 的总和不超过 10^5，并且 S 只包含大写字母和小写字母。

输出格式

对于每个测试用例，输出一个整数，表示包含 Tk 作为连续子串的循环移位数量。

样例

标准输入 标准输出
3 12
Rounddoggggggggggggggggg 8
6 0
RounddogRounddo
1
abcdefgabcdegf
2

题解

这个题我们需要匹配给定的字符串和输入的字符串。观察可以发现给定的字符串一定是以大写的R开头的，那么我们就可以在输入的字符串中只搜索R出现的位置，然后搜索到了就与Tk进行匹配，如果每一位都相同那么cnt++。同时要注意输入的字符串是可以进行循环移位的，那么我们就可以将s直接拼接在自己后面，这样相当于进行了循环移位，接下来的循环中就只用移动滑动窗口就行了。

接下来就是根据cnt的值求答案，如果cnt是0，答案显然是0，如果cnt是1，答案就是s的长度减去tk的长度再加一，可以理解为在保证tk连续的出现在s中的情况下任意循环移位。如果cnt大于1，那么任何循环移位都会至少有一个连续的tk出现在s中，因为循环移位最多破坏一个tk，另一个tk必定是完整的。

Problem C. 重测队列

**题目原地址：**https://ac.nowcoder.com/acm/contest/133879/C

输入文件： 标准输入
输出文件： 标准输出

一次大型比赛结束后，评测集群还要做一次复查：把 n 个程序在同一套 m 个测试点上重新评测。每个程序都会使用同一个测试点队列。

评测机处理一个程序时，会从队列开头依次运行测试点。一旦某个测试点给出拒绝结果，评测机在运行完这个测试点后立刻停止处理这个程序。通过全部测试点的程序会运行完整个队列。

复查开始前，历史日志已经给出了每个程序在每个测试点上的表现。第 i 个程序运行第 j 个测试点需要 d[i][j] 的时间，结果要么是接受，要么是拒绝。无论结果如何，只要这个测试点被实际运行，d[i][j] 都会计入集群总耗时。

你可以在复查前任意重排这 m 个测试点。求评测完全部 n 个程序所需的最小总耗时。

输入格式

第一行包含两个整数 n 和 m，分别表示程序个数和测试点个数。

接下来 n 行，第 i 行描述第 i 个程序。每行先包含 m 个整数 $d_{i,1}$, $d_{i,2}$, …,$d_{i,m}$，随后包含一个长度为 m 的字符串 s[i]。若 s[i] 的第 j 个字符为 A，表示第 i 个程序在第 j 个测试点上的结果是接受；若为 R，表示结果是拒绝。

保证：

  • 1 ≤ n ≤ 2×$10^4$
  • 1 ≤ m ≤ 20
  • 1 ≤ $d_{i, j}$ ≤ $10^9$
  • s[i] 仅包含字符 A 和 R

输出格式

输出一个整数，表示最小可能的总耗时。

样例

标准输入 标准输出
3 3 27
3 10 2 ARA
5 1 4 RAA
2 2 7 AAR

题解

这个题涉及到的算法有sos dp和状压dp。首先我们考虑将数据按照在第几位是R按二进制存起来，是R为1，不是为0。然后我们考虑怎样让一个状态的耗时总和最小，可以很自然的想到去考虑它的子集，在他的子集中找到加上下一个测试点后耗时最小的那一个，并将其赋值给这个状态。我们记dp[i]为**选取的测试点为i时所耗的最小时间。**例如，dp[3]中i的掩码为11，也就是已选取的测试点为1和2。

接下来我们要考虑R的情况，当一个程序的测试点的结果为R时，之后的测试点都不会运行，因此我们需要使用SOS dp，把所有之前存下来的时间数据根据R的掩码排列求前缀和，比如g[3] [j]就包括了g[1] [j]和g[2] [j]。基于此种变换，我们就可以很方便的算出cost。比如我们要求dp[7]，其掩码为111，子集是101，110，011，我们就可以遍历找到下标为这几个子集的数据，并将其加上cost。cost的计算方法为:假设此时掩码为mask，我们设一个步长step=1，每次将step左移一位，将左移的位数记作j，并和mask按位与运算，保证mask第j + 1位为1，然后我们对mask和1<<j进行异或运算，可以得到消除了第j+1位的mask，即mask的一个最大真子集，记这个真子集为prev，我们再对prev求补集，得到一个未选集合complement。程序i还没有停可以翻译为这个程序的掩码Ri和已选集合的交集是空集，即Ri是complement的子集。而g[complement] [j]又包含了complement的所有子集，即所有的还在运行的程序。因此cost = g[complement] [j], dp[mask] = min(dp[mask], dp[prev] + cost)。

Problem K. 转向导航

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

车载导航系统引导驾驶员沿着地图上绘制好的规划路线行驶。我们采用平面的标准方向：$x$ 轴正方向指向东，$y$ 轴正方向指向北。

路线由 $n$ 个航点 $P_1, P_2, \ldots, P_n$ 组成，每个航点具有整数坐标。汽车沿直线段行驶，始终向前移动：先从 $P_1$ 行驶到 $P_2$，再从 $P_2$ 行驶到 $P_3$，依此类推，直到到达 $P_n$。

每当汽车经过一个中间航点 $P_i$（$2 \le i \le n-1$）时，系统会播报驾驶员在该处的转弯情况。系统将汽车到达的方向（从 $P_{i-1}$ 到 $P_i$）与离开的方向（从 $P_i$ 到 $P_{i+1}$）进行比较：

  • 如果离开方向是由到达方向逆时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向左转，系统播报 LEFT；
  • 如果是由到达方向顺时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向右转，系统播报 RIGHT；
  • 如果方向完全不变，则汽车继续直行，系统播报 STRAIGHT。

保证汽车绝不会掉头，因此离开方向绝不会与到达方向恰好相反。于是，每个中间航点处恰好适用三种播报中的一种。

给定路线，按顺序输出每个中间航点的播报。

输入格式

每个测试文件包含多组测试数据。第一行包含测试数据的组数 $T$（$1 \le T \le 500$）。每组测试数据的格式如下：

每组测试数据的第一行包含一个整数 $n$（$3 \le n \le 10^5$），表示路线上的航点数。

接下来 $n$ 行，每行包含两个整数 $x_i$ 和 $y_i$（$-10^9 \le x_i, y_i \le 10^9$），表示第 $i$ 个航点 $P_i$ 的坐标，按汽车经过的顺序给出。保证每两个相邻航点互不相同（对所有 $1 \le i \le n-1$ 都有 $P_i \ne P_{i+1}$），且汽车绝不会掉头（对所有 $2 \le i \le n-1$，从 $P_i$ 到 $P_{i+1}$ 的方向与从 $P_{i-1}$ 到 $P_i$ 的方向不会恰好相反）。

保证同一测试文件中所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

输出格式

对于每组测试数据，输出中间航点 $P_2, P_3, \ldots, P_{n-1}$ 的播报。每个播报是字符串 LEFT、RIGHT 或 STRAIGHT 之一。

样例

standard input standard output
2 LEFT LEFT
4 STRAIGHT RIGHT
0 0
1 0
1 1
0 1
4
0 0
2 0
4 0
4 -2

本题不涉及算法，从数学角度分析即可。题目要求出中转点处的方向是左转还是右转，假设中转点是第k个点，那么k处的播报涉及到第k-1个点和第k+1个点，我们可以利用第k个和第k-1个点，第k个和第k+1个点的坐标求出两个向量，两个向量的夹角的正弦值就可以反映出播报的方向，因此我们将这两个向量做叉乘，如果是正的就是向左转，如果是负的就是向右转，如果是0就是直行。

Problem M. 可能连通罢（Maybe Connected）

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

小羊对于一个图中，两个点可能不相连但是连通这件事感到很讶异。两个点相连指的是两个点之间有边，而两个点连通指的是存在一条路径从一点出发到达另一点。

小羊给你一个 $n$ 个结点的没有边的图，并让你给这个图上新增 $m$ 条无向边。他希望你能最大化满足以下条件的点对 $(u, v)$（$u \ne v$）的数量：

  • $u$ 和 $v$ 不相连（即没有直接边）；
  • $u$ 和 $v$ 连通（即存在一条路径）。

图可能很大，所以你不需要完整输出这个图的各条边，只需输出这个对数的最大值即可。这里 $(u, v)$ 和 $(v, u)$ 被认为是相同的点对。

注意：图中不允许出现自环和重边。

输入格式

每个输入包含多个测试样例。输入的第一行包含测试样例的数量 $T$（$1 \le T \le 10^4$）。每个测试样例的输入格式如下：

每个测试样例有且仅有一行，包含两个整数 $n$ 和 $m$（$1 \le n \le 10^5$，$0 \le m \le \min(\frac{n(n-1)}{2}, 10^9)$）——分别表示结点的个数以及需要新增的边的数量。

输出格式

对于每个测试样例，输出一个整数，表示连通但不相连的点对 $(u, v)$（$u \ne v$）数量的最大值。

样例

标准输入 标准输出
3 1
3 2 0
4 6 3
5 3

题解

本题考察图的连通性相关的知识点。已知一个节点为n的图，若它是连通的，则至少有n-1条边。当节点为n并且边数为m的时候，若m<n，则原图可看作为一个由m+1个节点构成的树，每两个节点之间都是连通的，每条边会让两个节点相连，则连通但不相连的节点数量为:
$$
num = m(m+1)/2
$$

若m>=n，则原图的n个节点都是互相连通的。可以从完全图开始拆边，每拆一条边就会多一对符合条件的点。那么连通但不相连的节点数量为:
$$
num = n(n - 1) / 2
$$

Problem E. 排列求值

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$
f(P) = \sum_{0 \le i < j < n} (P_j - P_i)
$$

给定一个 0 到 $n-1$ 的排列 $P$，输出它的权值。

Input

第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

输出一行包含一个整数，表示排列的权值。

Example

standard input standard output
4 4
2 0 1 3

题解

这个题不涉及算法知识，涉及一些数学逻辑。

对于任意的位置k（下标从0到n），它会减去它之前的所有数，也会被它之后的所有数减去，也就是它的权值是
$$
P_k = k-(n-1-k)=2k-n+1
$$

Problem F. 排列生成

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$f(P) = \sum_{0 \le i < j < n} (P_j - P_i)$$

给定一个 0 到 $n-1$ 的排列 $P$，以及两个整数 $k$ 和 $x$（$0 \le k, x < n$）。要求构造一个 0 到 $n-1$ 的排列 $P’$，满足以下两个条件：

  • $P’_k = x$（即 $P’$ 的第 $k$ 个元素为 $x$，下标从 0 开始）；
  • $f(P’) \equiv f(P) \pmod{n}$。

如果有解，输出任意一组符合条件的排列 $P’$；如果无解，输出 $-1$。

Input

第一行包含三个整数 $n$（$1 \le n \le 2 \times 10^5$），$k$ 和 $x$（$0 \le k, x < n$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

如果无解，输出一行包含一个整数 $-1$。否则输出一行包含 $n$ 个整数，表示符合条件的排列 $P’$。

Example

standard input standard output
4 1 3 0 3 1 2
2 0 1 3

题解

本题是E题的延伸，已知有如下公式：
$$
(a + b) mod \ n \equiv(a mod\ n + b mod\ n)mod\ n\
(a * b) mod \ n \equiv(a mod\ n * b mod\ n)mod\ n
$$
结合一下E题的公式，会发现可以把排列加上任意的正整数k再模n，然后就可以得到一个与原来排列的权值同余的排列。题目中的输出-1是烟雾弹，不会有指定一个位置的数为某个数而导致生成不了符合条件的排列的情况。
