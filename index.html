Problem H. 困难问题

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个整数 n。请找出长度为 n 的字典序最小的排列 p，使得对于任意 1 ≤ i ≤ n，|p[i] - p[(i mod n) + 1]| 都不是质数。

输入格式

每个测试包含多个测试用例。第一行包含测试用例的数量 t（1 ≤ t ≤ 10^4）。接下来是测试用例的描述。

每个测试用例的唯一一行包含一个整数 n（2 ≤ n ≤ 2×10^5）。

保证所有测试用例中 n 的总和不超过 2×10^5。

输出格式

对于每个测试用例，如果不存在符合条件的长度为 n 的排列，请输出 -1。

否则，输出 n 个互不相同的整数 p1, p2, …, pn（1 ≤ pi ≤ n），表示你找到的排列 p。

样例

标准输入 标准输出
2 1 2
2 -1
3

题解

这是一个构造类问题，需要构造出一个字典序最小的排列使得每两个相邻的数字之差都不是质数，其中p[1]与p[n]相邻。很容易就能想到字典序最小则一定是以1开头，而且1也不是质数，因此我们可以直接按照从1到n进行排列，会发现只要满足n-1不是质数即可，其中偶数除了2以外都不是质数，也就是说n为奇数且不为3的时候一定可以构造出一个合法的排列。而如果n为偶数的话需要检查n-1是否是质数，可以使用埃氏筛来筛选质数并查找。如果n-1是质数的话，我们从后往前考虑，因为最好构建的非质数就是1，而结尾不能是n，那么我们将n到n-k颠倒过来，从第n-k位开始按照n，n-1，n-2…n-k的顺序构造，这样只要满足k+1不是质数且n-k-1不是质数即可，枚举发现k为3的时候满足条件，此时n大于等于8，因此我们将部分点特殊处理后进行普遍处理即可。（此规律也可通过打表找规律发现）

输入文件： 标准输入
输出文件： 标准输出
时间限制： 1 秒
内存限制： 256 MB

给定一个简单连通无向图 G，包含 n 个顶点和 m 条边，以及一个由 k 个特殊顶点 a1, a2, …, ak 组成的集合。G 有一个有趣的性质：所有顶点的度数不超过三。

考虑在 G 上进行的以下游戏：

  • 游戏由两名玩家 Alice 和 Bob 参与。初始时，Alice 站在一个非特殊顶点 s 上。然后，两名玩家轮流操作，由 Alice 先手：

    • 如果轮到 Alice 操作，假设她当前在顶点 u。如果 u 是特殊顶点，游戏结束且 Alice 获胜。否则，她选择一个与 u 有边相连的顶点 v 并移动到 v。如果不存在这样的顶点，游戏结束且 Bob 获胜。
    • 如果轮到 Bob 操作，他会选择 G 中剩余的任意一条边并将其删除。如果 G 中没有边了，他什么也不做。

  • 可以证明游戏会在有限回合内结束。在整个游戏过程中，Alice 的位置对两名玩家都是已知的。

一个顶点 u 被认为是必胜的，当且仅当：

  • u 不是特殊顶点；
  • 如果初始时 Alice 站在顶点 u 上，在双方都采取最优策略的情况下，她能赢得游戏。

找出所有必胜顶点。

接下来的 m 行，每行包含两个整数 u 和 v（1 ≤ u, v ≤ n, u ≠ v），表示连接顶点 u 和 v 的一条边。保证 G 不包含自环或重边。此外，保证所有顶点的度数不超过三。

题解

本题是一个博弈论问题，根据规则，很容易就能想到与特殊点相邻的点是必胜点，再往深了思考，轮到Bob的回合的时候，Alice要想赢，她就必须要有两条路可以获胜，这样不管Bob删除哪一条路，Alice都有另一个选择可以获胜。我们构造一种点称为安全点，只要处于这个点，此时不管轮到谁Alice都是必胜的。不难发现，特殊点都是安全点，并且基于刚才的分析，一个点是安全点，当且仅当这个点有两个邻居是安全点。因此我们可以从特殊点开始往外遍历，记录每一个点的安全点的邻居数，并不断更新，最终安全点里除去特殊点之外的点就是必胜点。

Problem C. 重测队列

如果存在两个格子 (r1, c1) 和 (r2, c2) 满足 r1 < r2 且 c1 < c2，且这两个格子中的数字相等，那么所有满足 r1 ≤ r ≤ r2 且 c1 ≤ c ≤ c2 的格子 (r, c) 都会被标记。

第一行包含两个整数 n、m（1 ≤ n, m，n × m ≤ 1000000）。

接下来 n 行，每行包含 m 个整数；其中第 i 行包含 a[i][1], a[i][2], …, a[i][m]（1 ≤ a[i][j] ≤ n × m），描述该数字网格。

输出 n 行，每行包含一个长度为 m、由字符 0 和 1 组成的字符串。

样例

标准输入 标准输出
2 6 001110
1 2 3 4 5 6 001110
7 8 9 3 4 10

题解

对每种数字独立处理。将数字 $v$ 的所有出现位置按行升序、同行按列升序排列（本题中用链表收集后反转即可得到该顺序）。由于只有跨行的配对（$r_1<r_2$）才会产生矩形，我们可将每行的点压缩为该行的最小列 $l_i$ 和最大列 $r_i$。

记该数字出现的行（去重排序）为 $\text{rows}1<\dots<\text{rows}k$，对应每行的 $l_i$ 和 $r_i$。定义前缀最小列 $p_l[i]=\min{1\le t\le i} l_t$ 和后缀最大列 $s_r[i]=\max{i\le t\le k} r_t$。

  • 对于 $\text{rows}i$ 和 $\text{rows}{i+1}$ 之间的空行（行号在 $\text{rows}i+1$ 到 $\text{rows}{i+1}-1$），若 $p_l[i] < s_r[i+1]$，则这些行被覆盖的列区间为 $[,p_l[i],, s_r[i+1],]$。
  • 对于有效行 $\text{rows}_i$ 本身：
    • 若它作为上方点（$i<k-1$ 且 $p_l[i]<s_r[i+1]$），产生区间 $[,p_l[i],, s_r[i+1],]$；
    • 若作为下方点（$i>0$ 且 $p_l[i-1]<s_r[i]$），产生区间 $[,p_l[i-1],, s_r[i],]$。
      该行的最终标记列区间是上述两区间的并集（有重叠则合并，否则分别为两个区间）。

对每种数字产生的所有矩形，使用二维差分进行区间加。全部处理完后求一次二维前缀和，标记次数 $>0$ 的格子输出 1，否则输出 0。总复杂度 $O(nm)$。

给定一棵以顶点 1 为根的树，树有 n 个顶点，编号从 1 到 n。

你需要构建一棵新树，同样以顶点 1 为根，使用相同的 n 个顶点，并满足以下条件：对于每个顶点 x ≠ 1，它在新树中的父顶点必须是 x 在原树中的祖先。

此外，给定 q 个约束。每个约束的形式为 (u, v)，表示在新树中 u 必须是 v 的后代，等价地，v 必须是 u 的祖先。

设 dep[i] 为顶点 i 在新树中的深度，其中根 1 的深度为 0。最小化 ∑dep[i]，并输出该最小值。

输入格式

每个测试文件仅包含一组测试数据。

第一行包含两个整数 n、q（2 ≤ n ≤ 500000，0 ≤ q ≤ 500000）。

接下来 n-1 行，每行包含一个整数；其中第 (i-1) 行包含一个整数 p[i]（1 ≤ p[i] < i），表示在原树中顶点 i 的父顶点是 p[i]。

接下来 q 行，每行包含两个整数 u、v（2 ≤ u ≤ n，1 ≤ v ≤ n），描述一个约束：在新树中 u 必须是 v 的后代。保证 u ≠ v，且 v 是 u 在原树中的祖先。

输出格式

输出一个整数：∑dep[i] 的最小可能值。

样例

标准输入 标准输出
7 4 11
1
2
3
3
2
6
4 2
4 3
5 2
7 2

题解

本题本质上是要在满足若干“祖先后代”约束的前提下，给每个节点（除根外）选择一个尽可能浅的祖先作为新父节点，以最小化深度之和。因为越浅的父节点意味着越小的深度，但必须满足所有给定约束，即 u 的父节点深度不能低于 depth[v]（v 是给定祖先）。

我们采用贪心策略从叶子向根处理：对于每个节点 u，维护一个集合，记录所有以 u 为下端点的约束——即所有要求 u 是某个祖先 v 的后代的约束。当为 u 选择父节点时，必须选一个深度至少为这些约束中最大深度的祖先。为了让 u 的深度尽量小，最优选择恰是这些约束中深度最大的那个 v 作为父节点；如果没有任何约束，直接选根 1 作为父节点。当 u 的父节点选定后，剩余未满足的约束（即来自 u 但深度小于选定父节点深度的那些）需要向上传递给选定的父节点继续处理，因为它们现在变成了对父节点的约束。

这一过程可以使用可并堆（左偏树）高效实现。具体做法：

  1. 读入原树，预处理每个节点的深度originaldepth。
  2. 对于每个约束 (u, v)，在节点 u 的可并堆中插入一个值为 v 的节点（按深度作为键值构建最大堆）。
  3. 从 n 到 2 逆序遍历节点 u（相当于自底向上），处理节点 u 的堆：
    • 取出堆顶元素 v（即深度最大的约束祖先）。如果堆顶有多个相同的 v，全部弹出（重复约束只计一次）。
    • 将 u 的新父节点设为 v。若堆为空，则父节点设为 1。
    • 将 u 的堆中剩余元素（已弹出重复 v 后剩下的）合并到父节点 v 的堆中，因为这些约束现在传递给了 v。
  4. 所有父节点确定后，从根向下计算新深度并累加即可得到答案。

由于每个约束只会被插入和弹出各一次，总复杂度为 O((n + q) log q)，可以轻松通过。

Problem M. 可能连通罢（Maybe Connected）

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

小羊对于一个图中，两个点可能不相连但是连通这件事感到很讶异。两个点相连指的是两个点之间有边，而两个点连通指的是存在一条路径从一点出发到达另一点。

小羊给你一个 $n$ 个结点的没有边的图，并让你给这个图上新增 $m$ 条无向边。他希望你能最大化满足以下条件的点对 $(u, v)$（$u \ne v$）的数量：

  • $u$ 和 $v$ 不相连（即没有直接边）；
  • $u$ 和 $v$ 连通（即存在一条路径）。

图可能很大，所以你不需要完整输出这个图的各条边，只需输出这个对数的最大值即可。这里 $(u, v)$ 和 $(v, u)$ 被认为是相同的点对。

注意：图中不允许出现自环和重边。

输入格式

每个输入包含多个测试样例。输入的第一行包含测试样例的数量 $T$（$1 \le T \le 10^4$）。每个测试样例的输入格式如下：

每个测试样例有且仅有一行，包含两个整数 $n$ 和 $m$（$1 \le n \le 10^5$，$0 \le m \le \min(\frac{n(n-1)}{2}, 10^9)$）——分别表示结点的个数以及需要新增的边的数量。

输出格式

对于每个测试样例，输出一个整数，表示连通但不相连的点对 $(u, v)$（$u \ne v$）数量的最大值。

样例

标准输入 标准输出
3 1
3 2 0
4 6 3
5 3

题解

本题考察图的连通性相关的知识点。已知一个节点为n的图，若它是连通的，则至少有n-1条边。当节点为n并且边数为m的时候，若m<n，则原图可看作为一个由m+1个节点构成的树，每两个节点之间都是连通的，每条边会让两个节点相连，则连通但不相连的节点数量为:
$$
num = m(m+1)/2
$$

若m>=n，则原图的n个节点都是互相连通的。可以从完全图开始拆边，每拆一条边就会多一对符合条件的点。那么连通但不相连的节点数量为:
$$
num = n(n - 1) / 2
$$

Problem E. 排列求值

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$
f(P) = \sum_{0 \le i < j < n} (P_j - P_i)
$$

给定一个 0 到 $n-1$ 的排列 $P$，输出它的权值。

Input

第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

输出一行包含一个整数，表示排列的权值。

Example

standard input standard output
4 4
2 0 1 3

题解

这个题不涉及算法知识，涉及一些数学逻辑。

对于任意的位置k（下标从0到n），它会减去它之前的所有数，也会被它之后的所有数减去，也就是它的权值是
$$
P_k = k-(n-1-k)=2k-n+1
$$

Problem F. 排列生成

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$f(P) = \sum_{0 \le i < j < n} (P_j - P_i)$$

给定一个 0 到 $n-1$ 的排列 $P$，以及两个整数 $k$ 和 $x$（$0 \le k, x < n$）。要求构造一个 0 到 $n-1$ 的排列 $P’$，满足以下两个条件：

  • $P’_k = x$（即 $P’$ 的第 $k$ 个元素为 $x$，下标从 0 开始）；
  • $f(P’) \equiv f(P) \pmod{n}$。

如果有解，输出任意一组符合条件的排列 $P’$；如果无解，输出 $-1$。

Input

第一行包含三个整数 $n$（$1 \le n \le 2 \times 10^5$），$k$ 和 $x$（$0 \le k, x < n$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

如果无解，输出一行包含一个整数 $-1$。否则输出一行包含 $n$ 个整数，表示符合条件的排列 $P’$。

Example

standard input standard output
4 1 3 0 3 1 2
2 0 1 3

题解

本题是E题的延伸，已知有如下公式：
$$
(a + b) mod \ n \equiv(a mod\ n + b mod\ n)mod\ n\
(a * b) mod \ n \equiv(a mod\ n * b mod\ n)mod\ n
$$
结合一下E题的公式，会发现可以把排列加上任意的正整数k再模n，然后就可以得到一个与原来排列的权值同余的排列。题目中的输出-1是烟雾弹，不会有指定一个位置的数为某个数而导致生成不了符合条件的排列的情况。
