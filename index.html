Problem K. 转向导航

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

车载导航系统引导驾驶员沿着地图上绘制好的规划路线行驶。我们采用平面的标准方向：$x$ 轴正方向指向东，$y$ 轴正方向指向北。

路线由 $n$ 个航点 $P_1, P_2, \ldots, P_n$ 组成，每个航点具有整数坐标。汽车沿直线段行驶，始终向前移动：先从 $P_1$ 行驶到 $P_2$，再从 $P_2$ 行驶到 $P_3$，依此类推，直到到达 $P_n$。

每当汽车经过一个中间航点 $P_i$（$2 \le i \le n-1$）时，系统会播报驾驶员在该处的转弯情况。系统将汽车到达的方向（从 $P_{i-1}$ 到 $P_i$）与离开的方向（从 $P_i$ 到 $P_{i+1}$）进行比较：

  • 如果离开方向是由到达方向逆时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向左转，系统播报 LEFT；
  • 如果是由到达方向顺时针旋转一个严格介于 $0^\circ$ 与 $180^\circ$ 之间的角度得到的，则驾驶员向右转，系统播报 RIGHT；
  • 如果方向完全不变，则汽车继续直行，系统播报 STRAIGHT。

保证汽车绝不会掉头，因此离开方向绝不会与到达方向恰好相反。于是，每个中间航点处恰好适用三种播报中的一种。

给定路线，按顺序输出每个中间航点的播报。

输入格式

每个测试文件包含多组测试数据。第一行包含测试数据的组数 $T$（$1 \le T \le 500$）。每组测试数据的格式如下：

每组测试数据的第一行包含一个整数 $n$（$3 \le n \le 10^5$），表示路线上的航点数。

接下来 $n$ 行，每行包含两个整数 $x_i$ 和 $y_i$（$-10^9 \le x_i, y_i \le 10^9$），表示第 $i$ 个航点 $P_i$ 的坐标，按汽车经过的顺序给出。保证每两个相邻航点互不相同（对所有 $1 \le i \le n-1$ 都有 $P_i \ne P_{i+1}$），且汽车绝不会掉头（对所有 $2 \le i \le n-1$，从 $P_i$ 到 $P_{i+1}$ 的方向与从 $P_{i-1}$ 到 $P_i$ 的方向不会恰好相反）。

保证同一测试文件中所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。

输出格式

对于每组测试数据，输出中间航点 $P_2, P_3, \ldots, P_{n-1}$ 的播报。每个播报是字符串 LEFT、RIGHT 或 STRAIGHT 之一。

样例

standard input standard output
2 LEFT LEFT
4 STRAIGHT RIGHT
0 0
1 0
1 1
0 1
4
0 0
2 0
4 0
4 -2

本题不涉及算法，从数学角度分析即可。题目要求出中转点处的方向是左转还是右转，假设中转点是第k个点，那么k处的播报涉及到第k-1个点和第k+1个点，我们可以利用第k个和第k-1个点，第k个和第k+1个点的坐标求出两个向量，两个向量的夹角的正弦值就可以反映出播报的方向，因此我们将这两个向量做叉乘，如果是正的就是向左转，如果是负的就是向右转，如果是0就是直行。

Problem M. 可能连通罢（Maybe Connected）

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 256 MB

小羊对于一个图中，两个点可能不相连但是连通这件事感到很讶异。两个点相连指的是两个点之间有边，而两个点连通指的是存在一条路径从一点出发到达另一点。

小羊给你一个 $n$ 个结点的没有边的图，并让你给这个图上新增 $m$ 条无向边。他希望你能最大化满足以下条件的点对 $(u, v)$（$u \ne v$）的数量：

  • $u$ 和 $v$ 不相连（即没有直接边）；
  • $u$ 和 $v$ 连通（即存在一条路径）。

图可能很大，所以你不需要完整输出这个图的各条边，只需输出这个对数的最大值即可。这里 $(u, v)$ 和 $(v, u)$ 被认为是相同的点对。

注意：图中不允许出现自环和重边。

输入格式

每个输入包含多个测试样例。输入的第一行包含测试样例的数量 $T$（$1 \le T \le 10^4$）。每个测试样例的输入格式如下：

每个测试样例有且仅有一行，包含两个整数 $n$ 和 $m$（$1 \le n \le 10^5$，$0 \le m \le \min(\frac{n(n-1)}{2}, 10^9)$）——分别表示结点的个数以及需要新增的边的数量。

输出格式

对于每个测试样例，输出一个整数，表示连通但不相连的点对 $(u, v)$（$u \ne v$）数量的最大值。

样例

标准输入 标准输出
3 1
3 2 0
4 6 3
5 3

题解

本题考察图的连通性相关的知识点。已知一个节点为n的图，若它是连通的，则至少有n-1条边。当节点为n并且边数为m的时候，若m<n，则原图可看作为一个由m+1个节点构成的树，每两个节点之间都是连通的，每条边会让两个节点相连，则连通但不相连的节点数量为:
$$
num = m(m+1)/2
$$

若m>=n，则原图的n个节点都是互相连通的。可以从完全图开始拆边，每拆一条边就会多一对符合条件的点。那么连通但不相连的节点数量为:
$$
num = n(n - 1) / 2
$$

Problem E. 排列求值

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$
f(P) = \sum_{0 \le i < j < n} (P_j - P_i)
$$

给定一个 0 到 $n-1$ 的排列 $P$，输出它的权值。

Input

第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

输出一行包含一个整数，表示排列的权值。

Example

standard input standard output
4 4
2 0 1 3

题解

这个题不涉及算法知识，涉及一些数学逻辑。

对于任意的位置k（下标从0到n），它会减去它之前的所有数，也会被它之后的所有数减去，也就是它的权值是
$$
P_k = k-(n-1-k)=2k-n+1
$$

Problem F. 排列生成

Input file: standard input
Output file: standard output
Time limit: 1 second
Memory limit: 1024 megabytes

对于一个 0 到 $n-1$ 的排列 $P$，定义它的权值为：

$$f(P) = \sum_{0 \le i < j < n} (P_j - P_i)$$

给定一个 0 到 $n-1$ 的排列 $P$，以及两个整数 $k$ 和 $x$（$0 \le k, x < n$）。要求构造一个 0 到 $n-1$ 的排列 $P’$，满足以下两个条件：

  • $P’_k = x$（即 $P’$ 的第 $k$ 个元素为 $x$，下标从 0 开始）；
  • $f(P’) \equiv f(P) \pmod{n}$。

如果有解，输出任意一组符合条件的排列 $P’$；如果无解，输出 $-1$。

Input

第一行包含三个整数 $n$（$1 \le n \le 2 \times 10^5$），$k$ 和 $x$（$0 \le k, x < n$）。
第二行包含 $n$ 个整数 $P_0, P_1, \dots, P_{n-1}$，表示给定的 0 到 $n-1$ 的排列。

Output

如果无解，输出一行包含一个整数 $-1$。否则输出一行包含 $n$ 个整数，表示符合条件的排列 $P’$。

Example

standard input standard output
4 1 3 0 3 1 2
2 0 1 3

题解

本题是E题的延伸，已知有如下公式：
$$
(a + b) mod \ n \equiv(a mod\ n + b mod\ n)mod\ n\
(a * b) mod \ n \equiv(a mod\ n * b mod\ n)mod\ n
$$
结合一下E题的公式，会发现可以把排列加上任意的正整数k再模n，然后就可以得到一个与原来排列的权值同余的排列。题目中的输出-1是烟雾弹，不会有指定一个位置的数为某个数而导致生成不了符合条件的排列的情况。
